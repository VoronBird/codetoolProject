# CodeTool
## Что это за проект?
проект является сайтом направленным на облегчения жизни разработчиков путём объединения в себя нескольких полезных инструментов для кодинга. 
### Инструменты
#### 1. Хранилище сниппетов
пользователи могут добавлять свои сниппеты для последующего их использования
#### 2. Справоник
небольшой справочник хранящий данные о некоторых языках и фреймворках, данные редактируются только администратором
#### 3.ИИ Ассистент
всторенный API нейросети, которая поможет в вопросах разработки, но не поддерживает вайбкодинг
## Запуск проекта
### Установка и запуск бэкенда

#### 1. Открыть терминал в папке `backend/`
        cd backend

#### 3. Активировать venv:
          Windows (Git Bash): source venv/Scripts/activate

#### 4. Установить зависимости:
          pip install -r requirements.txt

#### 5. Запустить сервер:
          uvicorn app.main:app --reload
  Сервер доступен на http://localhost:8000

### Установка и запуск фронтенда

#### 1. Открыть терминал в папке `frontend/`
          cd frontend

#### 2. Запустить:
          npm run dev
  Фронтенд доступен на http://localhost:5173



## Структура проекта
        CodeTool/
        ├── backend/                  # Серверная часть: обработка данных
        │   └── app/
        │       ├── routers/          # Роутеры: передача данных
        │       ├── schemas/          # Схемы: создание классов
        │       ├── services/         # Сервисы: обработка данных и обращение к БД
        │       ├── main.py           # Точка входа: сборка бэкенда воедино
        │       ├── db.py             # Настройка базы данных
        │       └── codetool.db       # База данных
        │
        └── frontend/                 # Клиентская часть: отображение данных пользователю
            ├── api/                  # Связь с роутерами бэкенда
            ├── App.tsx               # Сборка страницы
            └── App.css               # Редактирование стиля страницы
